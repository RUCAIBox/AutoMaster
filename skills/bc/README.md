# BrowseComp / web search

Three selected original skills from AutoMaster research runs. Each skill is a self-contained directory with a `SKILL.md` entrypoint.

| Skill | When it is useful | Evidence in the archive |
|---|---|---|
| [recover-search-anchor](recover-search-anchor/SKILL.md) | Escape a stalled search by identifying and relaxing the unsupported assumption in the query. | Paired episode-identification case; both executions succeeded. |
| [measured-relations](measured-relations/SKILL.md) | Preserve endpoints, travel mode and units when using distance evidence. | Paired distance case; both executions succeeded and local behavior differs. |
| [source-terms](source-terms/SKILL.md) | Retrieve missing facts in the vocabulary and language of the source while preserving entity identity. | Paired person-disambiguation case; language switching alone was not the distinguishing behavior. |
